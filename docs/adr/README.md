# Architectural Decision Records (ADR)

Store one architectural decision per `docs/adr/<domain>/<decision-slug>.md`,
using meaningful slugs without global numeric prefixes and the Michael Nygard
sections: **Status**, **Context**, **Decision**, and **Consequences**.
Link each ADR from its owning feature specification.
